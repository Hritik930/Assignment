## Steps
1. **VS Code** – open it, then *Help → About* (note the version).
2. **Node.js** – open the VS Code terminal (`` Ctrl+` ``) and run:
   ```bash
   node -v
   npm -v
   ```
3. **Live Server** – Extensions panel (`Ctrl+Shift+X`) → search *Live Server* by Ritwick Dey → Install. Open any `.html` file → right-click → **Open with Live Server** (or click *Go Live* in the status bar).
4. Arrange the window so that **VS Code, the terminal output (`node -v`), the Live Server extension and the browser tab running on `127.0.0.1:5500`** are all visible, then take the screenshot.
