200 × 80

Calculation (default box-sizing: content-box)

Total width 200 + (20×2) + (10×2) = 260px (+60px margin = 320px of horizontal space)
Total height 80 + (20×2) + (10×2) = 140px (+60px margin = 200px)

With box-sizing: border-box

The same width: 200px would already include padding and border, so the box would stay 200px wide and the content shrinks to 140px. That's why most developers add * { box-sizing: border-box; }.
