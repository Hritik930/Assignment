Design Choices

Colour: deep blue (trust, professionalism) with an orange accent only on actions so users find buttons quickly.

Typography: system font stack for fast loading; 1.6 line-height for readable paragraphs.

Layout: content capped at 800px so lines stay comfortable to read; white cards on a light-grey background create depth.

Maintainability: colours live in CSS variables so the theme can change in one place.
